# Komal Kumari - Portfolio

A React + Vite portfolio. All content lives in `src/data.js`.

## Run locally
```bash
npm install
npm run dev
```
Open the URL it prints (usually http://localhost:5173).

## Build
```bash
npm run build     # output in dist/
npm run preview   # preview the build
```

## Deploy
Upload the project to GitHub, then host it free on Vercel or Netlify (import the repo, build command `npm run build`, output `dist`).
